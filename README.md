# 🌐 Single-File Shopping Website

This is a **fully responsive single-file website** built using **pure HTML, CSS, and JavaScript**.  
All sections — **Home, Shop, Blog, About, Contact** — are combined into a single `index.html` file.

## 🚀 Features

- Smooth scrolling navigation  
- Mobile-friendly hamburger menu  
- Dynamic shop items (JavaScript rendered)  
- Add-to-cart counter  
- Blog posts with modal popup  
- About section  
- Contact form using `mailto:`  
- Full CSS + JS inside one HTML file  
- No Tailwind / No frameworks
